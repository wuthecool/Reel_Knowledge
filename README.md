Reel Knowledge was inspired by the trivia game Krillion.
Reel Knowledge allows a user to attempt to catch fish with ranging rarities. Each fish has a point threshold needed to reel it in. More obscure answers to trivia questions allows for more points.
We built Reel Knowledge using Figma, Chatgpt, and VSCODE (Typescript,HTML,CSS,JavaScript)
An accomplishment that we're proud of is getting the cutscene animations to fit in with our game. Another accomplishment is being able to utilize AI to assign point values for user inputs.
We hope to expand Reel Knowledge to have larger libraries and possibly use machine learning to better the scoring
